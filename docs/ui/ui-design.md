## Componentes reutilizables

- SpaceCard

## Organización

La interfaz se divide en:

- Screens: Pantallas completas.
- Components: Elementos reutilizables.

## Justificación

Esta separación mejora la legibilidad, reutilización y mantenimiento del código.
